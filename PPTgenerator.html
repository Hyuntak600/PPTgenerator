번역 서버(LibreTranslate) 설치 안내

번역 기능에는 내 컴퓨터에서 도는 번역 서버(LibreTranslate)가 필요해요. 번역 말고 다른 기능은 서버 없이도 모두 쓸 수 있어요. 이 안내는 위쪽 번역 서버 안내 버튼으로 언제든 다시 볼 수 있어요.

처음 한 번만: ① Docker Desktop 설치 → ② 명령 한 줄 실행. 다음부터는 Docker Desktop만 켜 두면 돼요.
내 컴퓨터

1. Docker Desktop 설치

  1. docker.com/products/docker-desktop에서 내 컴퓨터에 맞는 버전을 받아 설치하세요. Mac은 Apple 칩용과 Intel용이 따로 있어요(왼쪽 위 Apple 메뉴 → 이 Mac에 관하여에서 확인).
  2. 설치 후 Docker Desktop을 한 번 실행하고, "Docker Desktop is running"이 보일 때까지 기다리세요. 처음 실행할 때 "확인되지 않은 개발자" 경고가 뜨면, docker.com에서 받은 것이 맞는 한 열기를 눌러 진행하세요.

2. 번역 서버 실행

PowerShell 또는 명령 프롬프트터미널 앱을 열고, 아래 한 줄을 붙여넣어 Enter를 누르세요.

docker run -d -p 5000:5000 -e LT_LOAD_ONLY=en,ko,zh,id libretranslate/libretranslate
  • 처음에는 내려받느라 몇 분 걸려요. 위쪽 배너가 초록색이 되면 준비 끝이에요.
  • 긴 영문·숫자 한 줄이 나오고 입력 창으로 돌아오면 정상이에요. 터미널 창은 닫아도 돼요.
Docker Desktop은 계속 켜 두세요. 끄면 번역 서버도 함께 꺼져요.
Mac: 연결이 안 되면 AirPlay 수신 모드(5000번 포트 충돌) 때문일 수 있어요. 아래 4. 문제 해결을 보세요.
명령은 무슨 뜻인가요?
  • -d : 서버를 뒤에서(백그라운드로) 실행해서, 창을 닫아도 계속 켜져 있어요.
  • LT_LOAD_ONLY=en,ko,zh,id : 영어·한국어·중국어·인도네시아어 데이터만 불러와서 더 빨리 켜지고 메모리를 덜 써요.

다음에 다시 쓸 때

Docker Desktop을 켜고 Containers 탭에서 libretranslate 줄의 ▶를 누르세요. 위 명령을 또 실행하면 컨테이너가 쌓이니, 쓰지 않는 건 휴지통 버튼으로 지워도 돼요.

3. 연결 확인

위쪽 상태 배너(또는 칩)가 초록색 “연결 정상”이면 바로 쓰세요. 켠 직후에는 1~2분 걸릴 수 있고, 안 되면 배너의 다시 확인을 눌러 보세요.

서버 주소 (기본 http://localhost:5000 · 포트를 바꿔 실행했을 때만 고치세요)

4. 문제 해결

배너가 계속 “연결할 수 없습니다”라고 떠요
  • Docker Desktop이 켜져 있는지 확인하세요.
  • Containers 탭에서 libretranslate가 실행 중(초록색)인지 보고, 멈춰 있으면 ▶를 누른 뒤 1~2분 뒤 배너의 다시 확인을 누르세요.
  • 컨테이너 줄을 눌러 Logs를 보면 서버가 지금 무엇을 하는지 알 수 있어요.
“docker: command not found”라고 떠요

Docker Desktop이 설치되지 않았거나, 설치 후 재시작하지 않은 경우가 많아요. Docker Desktop을 먼저 켜서 완전히 실행된 뒤 다시 해 보세요.

“port is already allocated”라고 떠요

이미 번역 서버가 켜져 있다는 뜻일 수 있어요. 명령을 다시 실행하지 말고 그대로 쓰세요. Mac에서 계속 안 되면 아래 AirPlay 항목도 보세요.

일부 언어만 “모델이 없다”고 떠요

명령의 LT_LOAD_ONLY=en,ko,zh,id가 빠졌거나 오타가 있는지 확인하고, 기존 컨테이너를 지운 뒤 2번 명령을 다시 실행하세요.

번역 화면 대신 403이 떠요 (Mac · AirPlay)

Mac은 5000번 포트를 AirPlay 수신 모드가 쓰는 경우가 있어요. 둘 중 하나를 하세요.

  1. 시스템 설정 → 일반 → AirDrop 및 Handoff → AirPlay 수신 모드를 끄고 그대로 쓰기
  2. 아래 명령으로 5001번에서 다시 실행하고(쓰던 컨테이너는 먼저 지우세요), 위 3번의 서버 주소를 http://localhost:5001로 바꿔 저장하기
docker run -d -p 5001:5000 -e LT_LOAD_ONLY=en,ko,zh,id libretranslate/libretranslate
번역만 안 돼요 (Mac 사파리)

사파리는 https로 연 페이지가 http 번역 서버에 연결하는 것을 막을 수 있어요. 번역이 안 되면 크롬으로 열어 보세요.

서버가 켜졌는지 직접 보기 (고급)
  • 터미널에 docker ps -a를 입력해 libretranslate 줄의 STATUS를 보세요. Up ...이면 켜진 것, Exited ...이면 꺼진 것이에요(docker logs 컨테이너ID의 마지막 몇 줄이 이유를 알려줘요).
  • 브라우저 주소창에 http://localhost:5000을 열어 LibreTranslate 화면이 뜨면 서버는 정상이에요(켠 직후엔 1~2분 뒤). 그다음 배너의 다시 확인을 누르세요.

이 서버는 여러분 컴퓨터 안에서만 실행되며, 문장이 외부로 전송되지 않고 로컬에서 번역됩니다.

성경 DB 사용 안내

성경 DB 모드를 쓰기 전에 꼭 읽어 주세요.

이 구절들은 어디에 있나요?

  • 여기 있는 성경 구절은 전부 프로그램에 기록되어 있는 것이에요.
  • 구절은 수정할 수 있어요. 다만 수정한 내용이 프로그램에 자동으로 업데이트되지는 않아요. (이 PC에만 남아요)

수정한 내용을 프로그램에 반영하려면

  • 슬라이드 작업을 마친 뒤 DB 코드 복사에서 ② 아직 안 보낸 것을 누르면 날짜와 상관없이 고치고 아직 안 보낸 절이 한 번에 모여요. 복사한 코드를 프로그램 관리자()에게 보낸 뒤 보냈어요를 눌러 두면, 그다음부터는 새로 고친 절만 모여요. (① 지금 보고 있는 절은 지금 화면에 열려 있는 절 하나의 코드예요. 절 목록의 ✎는 아직 안 보낸 수정, ✓는 보냈다고 표시한 수정이에요.) 확인 후 프로그램을 업데이트할게요.

슬라이드를 만들 때는

  • 슬라이드를 만들 때는 전체 복사를 사용하면 돼요. 성경·장·절을 맥 스타일 메뉴로 고르면 그 글이 아래에 나와요(처음엔 보던 절만 나오고, 끝 절을 바꾸면 그 범위까지 나와요). 한 절이 여러 페이지면 16 (a) · 16 (b)처럼 나뉘어 보여요. 슬라이드 만들기 모드에서는 슬라이드 메뉴로 복사할 범위를 고를 수 있어요(기본은 전부).

모든 데이터 삭제

  • 로컬 데이터는 작업한 그 PC에 계속 남아 있어요.
  • 상단의 모든 데이터 삭제 버튼을 누르면 이 PC에 저장된 원고·백업·번역 캐시·설정이 없어져요. 성경 DB는 내가 수정한 구절까지 포함해 절대 지워지지 않아요.

다국어 자막 정렬 도구

언어별 원고를 문장 단위로 나눠 한 슬라이드에 짝지어 보고, 확인한 뒤 텍스트로 복사해 가는 도구예요.

🚀 이렇게 써요

  1. 언어별 칸에 원고를 붙여넣어요.
  2. 문장이 끝나는 곳에서 Enter로 나눠요. N번 조각이 N번 슬라이드에 들어가요.
  3. 오른쪽 슬라이드에서 언어끼리 짝이 맞는지 확인해요. 슬라이드마다 글자 크기·정렬도 바꿀 수 있어요.
  4. 📋 전체 텍스트 복사로 가져가요.

성경 구절 언어 번역 결과

기계번역이라, 뜻이 끝나는 한 덩어리씩 드래그하면 원문과 번역을 비교하기 좋아요. 예) “하나님이 세상을 이처럼 사랑하사 독생자를 주셨으니”만 선택해 보세요. 번역에는 번역 서버(🐳 번역 서버 안내)가 필요해요.

  1. 번역 소스를 다운받아야 작동해요. (🐳 번역 서버 안내 참고)
  2. 번역 소스는 예열이 될수록 더 잘 작동해요. 처음엔 느리거나 어색해도 몇 번 쓰다 보면 나아져요.

🆕 최신 패치노트2026-09-30

  • 📖 성경 DB 모드가 생겼어요. 위쪽 버튼으로 슬라이드 만들기와 오갈 수 있고, 성경·장·절·페이지를 골라 4개 언어 본문을 입력해요. 🧩 DB 코드 복사로 bible/ 폴더의 장 파일에 붙여넣을 코드를 만들어요. DB 모드에는 전체 삭제가 없어요.
  • 슬라이드 만들기 모드의 🧹 로컬 데이터·캐시 삭제로 원고·자동 백업·번역 캐시·설정을 한 번에 지울 수 있어요. 성경 DB 초안은 지워지지 않아요.
  • 슬라이드마다 글자 크기(pt)와 왼쪽 / 가운데 / 오른쪽 정렬을 따로 정할 수 있어요. 위쪽 기준 글자 크기(기본 80pt)는 모든 슬라이드의 목표 크기예요. 툴바의 기본 정렬은 전체 기본값이고. 전체 텍스트 복사에는 글자 크기가 문단 앞에 표시돼요.
  • 📋 전체 텍스트 복사는 창을 여는 것만으로는 복사하지 않아요. 창 안의 복사를 눌러야 복사돼요.
  • 복사 글의 문단 맨 앞에 [번호 · 글자 크기](예: [1 · 80pt])가 붙어요. 글자 크기는 자동 축소까지 반영된 실제 값이에요.
  • 글자를 드래그했을 때의 번역 결과 언어가 처음부터 English로 설정돼요(세부 설정에서 한국어로 바꿀 수 있어요).
  • 처음 화면을 지금의 시작 안내로 바꿨어요. 위쪽 ℹ️ 시작 안내로 언제든 다시 볼 수 있어요.

🛠 개발자 노트

  • 번역문은 기계번역이라 언어끼리 같은 내용이 들어갔는지 대조하는 참고용이에요. 최종 원고 검수를 대신하지는 않아요.
  • 슬라이드별 글자 크기·정렬은 슬라이드 번호 기준으로 저장돼요. 조각을 합치거나 나눠서 번호가 밀리면 설정은 그 번호에 남아요.
  • 원고와 설정은 이 브라우저에만 자동 저장돼요. 다른 컴퓨터나 브라우저로는 옮겨지지 않아요.
  • PPTX로 저장하는 기능은 없앴어요. 이제 전체 텍스트 복사로 글자를 가져가요.
  • 예시 성경 본문은 저작권이 만료된 번역(개역한글, KJV, 和合本, 인도네시아어 Terjemahan Lama)이에요.

🐳 번역 서버(LibreTranslate) 설치 안내

이 도구는 참고번역·미리보기 번역을 위해 여러분 컴퓨터 안에서 LibreTranslate라는 번역 프로그램이 함께 켜져 있어야 합니다. 아래 순서를 딱 한 번만 따라 하면, 다음부터는 Docker Desktop에서 서버를 다시 켜기만 하면 됩니다. 이 안내는 언제든 위쪽 🐳 번역 서버 안내 버튼으로 다시 볼 수 있습니다.

1. Docker Desktop 설치 (한 번만)

Docker는 번역 프로그램을 컴퓨터에 깔끔하게 담아 실행해주는 무료 프로그램입니다.

  1. docker.com/products/docker-desktop 접속
  2. 내 컴퓨터에 맞는 버전(Windows / Mac) 다운로드 후 설치 — 설치 중 나오는 창은 기본값 그대로 "다음"만 눌러도 됩니다
  3. 설치가 끝나면 Docker Desktop 앱을 한 번 실행하고, 화면 좌측 하단(또는 상단바)에 "Docker Desktop is running" 같은 표시가 뜰 때까지 기다리기
Mac을 쓰신다면 처음 실행할 때 "확인되지 않은 개발자" 경고가 뜰 수 있는데, 공식 배포처(docker.com)에서 받은 것이라면 안내에 따라 열기를 진행하시면 됩니다.

2. 번역 서버 실행하기 (처음 한 번)

Windows PowerShell 또는 명령 프롬프트를 열기  /  Mac 터미널(Terminal) 앱을 열기

연 창에 아래 한 줄을 그대로 복사해서 붙여넣고 Enter를 누르세요.

docker run -d -p 5000:5000 -e LT_LOAD_ONLY=en,ko,zh,id libretranslate/libretranslate
  • -d 는 서버를 뒤에서(백그라운드로) 실행한다는 뜻이라, 실행 후 이 창을 닫아도 서버는 계속 켜져 있습니다.
  • LT_LOAD_ONLY=en,ko,zh,id 는 영어·한국어·중국어·인도네시아어 번역 데이터만 불러오게 해서, 서버가 더 빨리 켜지고 메모리도 덜 씁니다.
  • 맨 처음 한 번은 프로그램과 언어 데이터를 인터넷에서 내려받느라 몇 분 정도 걸릴 수 있습니다.
  • 명령을 실행하면 영문·숫자가 길게 이어진 한 줄(컨테이너 ID)이 나오고 곧바로 입력 창으로 돌아옵니다. 정상입니다. 서버가 완전히 준비될 때까지 1~2분 더 걸릴 수 있으니, 이 도구 위쪽 배너가 초록색이 될 때까지 기다려 주세요.
터미널 창은 닫아도 되지만, Docker Desktop 앱은 켜 두세요. Docker Desktop을 종료하면 번역 서버도 함께 꺼집니다.

다음에 다시 쓸 때 (컴퓨터를 껐다 켠 뒤)

  1. Docker Desktop 앱을 실행하고 완전히 켜질 때까지 기다리기
  2. 왼쪽 메뉴의 Containers 탭에서 libretranslate/libretranslate 컨테이너 줄의 ▶ (Start) 버튼 누르기

위 명령을 다시 실행해도 켜지긴 하지만, 그때마다 새 컨테이너가 하나씩 더 만들어져 쌓입니다. 쓰지 않는 컨테이너는 Containers 탭에서 휴지통 버튼으로 지워도 됩니다.

3. 연결 확인

  • 화면 위쪽(툴바 아래)에 뜨는 상태 배너를 확인하세요. 서버를 켠 직후에는 1~2분 걸릴 수 있어요
  • 초록색 "연결 정상" → 바로 쓰시면 됩니다
  • 노란색 경고 문구가 뜨면 → 위 2번 단계(서버 실행)를 먼저 하셨는지 확인 후, 배너의 다시 확인 버튼을 눌러보세요

서버 주소 (기본 http://localhost:5000 · 포트를 바꿔 실행했을 때만 고치세요)

4. 연결이 안 될 때 (하나씩 확인)

① 서버가 실제로 켜졌는지 보기

  • 터미널에 docker ps -a 를 입력해 libretranslate 줄의 STATUS를 확인하세요. Up ... 이면 켜져 있는 것이고, Exited ... 이면 꺼진 것입니다 (꺼졌다면 docker logs 컨테이너ID 의 마지막 몇 줄이 원인을 알려줍니다)
  • PORTS 칸에 0.0.0.0:5000->5000/tcp 가 보여야 합니다

② 인터넷 브라우저에서 서버를 직접 열어보기

  • 브라우저 주소창에 http://localhost:5000 을 입력하세요. LibreTranslate 번역 화면이 뜨면 서버는 정상입니다(처음 켠 직후에는 1~2분 뒤에 열립니다). 이 도구 배너의 다시 확인을 눌러보세요
  • 화면이 안 뜨거나 "Access denied / 403" 같은 게 뜨면 아래 Mac 포트 충돌을 확인하세요

Mac에서 5000번이 안 될 때 (포트 충돌)

  • 최근 macOS는 5000번 포트를 AirPlay 수신 모드가 쓰고 있어서, 서버가 켜져도 여기로 연결이 안 될 수 있습니다. 쓰던 컨테이너를 지우고 아래처럼 5001번으로 다시 실행한 뒤, 위 3번의 서버 주소를 http://localhost:5001 로 바꿔 저장하세요 docker run -d -p 5001:5000 -e LT_LOAD_ONLY=en,ko,zh,id libretranslate/libretranslate (또는 시스템 설정 → 일반 → AirDrop 및 Handoff → AirPlay 수신 모드를 끄고 5000번을 그대로 써도 됩니다)

5. 그 밖의 문제

배너가 계속 "연결할 수 없습니다"라고 뜸

  • Docker Desktop 앱이 켜져 있는지 확인(꺼져 있으면 먼저 실행)
  • Docker Desktop의 Containers 탭에서 libretranslate 컨테이너가 실행 중(초록색)인지 확인. 멈춰 있으면 ▶ 버튼을 누르고 1~2분 기다린 뒤 배너의 다시 확인을 눌러보세요
  • 컨테이너 줄을 눌러 Logs를 보면 서버가 지금 무엇을 하는지 볼 수 있습니다

"docker: command not found" 같은 에러가 뜸

  • Docker Desktop 설치가 안 됐거나, 설치 후 컴퓨터를 재시작하지 않은 경우가 많습니다. Docker Desktop 앱을 먼저 실행해서 완전히 켜진 뒤 다시 시도해 보세요

"port is already allocated" 같은 에러가 뜸

  • 이미 번역 서버가 켜져 있다는 뜻입니다. 명령을 다시 실행할 필요 없이 그대로 쓰시면 됩니다

일부 언어만 "모델이 설치돼 있지 않다"고 뜸

  • 명령에서 LT_LOAD_ONLY=en,ko,zh,id 부분이 빠졌거나 오타가 없는지 확인하고, 기존 컨테이너를 지운 뒤 2번 명령을 그대로 다시 실행해 보세요

이 서버는 여러분 컴퓨터 안에서만 실행되며, 문장이 외부로 전송되지 않고 로컬에서 번역됩니다.
